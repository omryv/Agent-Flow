# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report security vulnerabilities by emailing:

agentflow@trace.observer

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix if known

You will receive a response within **48 hours** acknowledging receipt.
We will aim to release a fix within **90 days** depending on severity.

We ask that you give us reasonable time to address the issue before
any public disclosure.
